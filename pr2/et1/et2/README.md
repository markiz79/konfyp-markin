# Вариант 15. Этап 1

Консольное приложение считывает настройки из TOML-файла, проверяет их
и выводит в формате «ключ = значение». При неверных настройках выводится
сообщение об ошибке. Получение зависимостей и построение графа на этом
этапе не выполняются.

## Функции

- `check_text(config, key)` — проверка строкового параметра.
- `check_repository(value, test_mode, folder)` — проверка URL или тестового файла.
- `check_output(value, folder)` — проверка имени изображения.
- `validate_config(config, folder)` — проверка состава и значений настроек.
- `load_config(path)` — чтение и проверка TOML-файла.
- `main()` — обработка аргумента запуска, вывод настроек или ошибки.

## Настройки

Все пять параметров обязательны и задаются в TOML без секции.

| Параметр | Описание |
| --- | --- |
| `package` | Имя пакета: латинские буквы, цифры, `.`, `_`, `-`; начало и конец — буква или цифра. В тестовом режиме — заглавные латинские буквы. |
| `repository` | HTTP(S)-URL или путь к существующему тестовому файлу. Относительный путь отсчитывается от папки конфигурации. |
| `test_mode` | Тестовый режим: `true` или `false` без кавычек. |
| `output` | Имя будущего PNG-файла без пути. |
| `max_depth` | Максимальная глубина анализа: целое неотрицательное число. `0` — только исходный пакет. |

Неизвестные параметры и пустые строки не допускаются.

## Запуск и тестирование

Python 3.11 или новее. Сборка и сторонние библиотеки не требуются.
Команды выполняются из корня проекта.

Запуск с `config.toml`:

```sh
python src/main.py
```

Запуск с тестовой конфигурацией:

```sh
python src/main.py examples/test.toml
```

Запуск тестов:

```sh
python -m unittest discover -s tests -v
```

## Примеры использования

Конфигурация `config.toml`:

```toml
package = "requests"
repository = "https://pypi.org"
test_mode = false
output = "graph.png"
max_depth = 3
```

Результат запуска:

```text
package = requests
repository = https://pypi.org
test_mode = false
output = graph.png
max_depth = 3
```

Примеры обработки ошибочных значений:

| Значение в конфигурации | Сообщение |
| --- | --- |
| `package = "my package"` | `Ошибка: package: недопустимое имя пакета` |
| `repository = "pypi.org"` | `Ошибка: repository: требуется URL http:// или https://` |
| `test_mode = "false"` | `Ошибка: test_mode: требуется true или false без кавычек` |
| `output = "graph.jpg"` | `Ошибка: output: требуется имя файла с расширением .png` |
| `max_depth = -1` | `Ошибка: max_depth: число должно быть неотрицательным` |
